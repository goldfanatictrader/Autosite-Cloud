## Features

### Phase 1 — MVP
- Site Dashboard with overview cards
- AI Content Writer (one-line brief → full site copy)

### Phase 2
- One-Tap Publish with build progress
- Multi-Site Manager with templates
- Custom Domain Setup with auto-HTTPS

### Phase 3
- Traffic Insights and analytics
- Account & Sign In (social + email)

### Phase 4
- Notifications & Alerts
